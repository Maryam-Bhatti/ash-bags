# Ash Bags

A responsive demo handbag storefront built with Next.js App Router, TypeScript, React, and Tailwind CSS. The sample catalog uses PKR prices, locally supplied handbag photos, and original fallback illustrations. The site includes dedicated About and Contact pages; contact details are marked as demo placeholders.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to browse the storefront.

## Available checks

```bash
npm run lint
npm run build
```

## Demo behavior

- Cart contents are stored in this browser's local storage.
- Checkout validates the sample delivery form and displays a demo confirmation. No order is sent, no payment is taken, and no delivery is arranged.
- Product availability, customer testimonials, and contact details are sample storefront content.
